# 05 — UI/UX Planning

## Design goals from the presentation
- Student-friendly and straightforward
- Trustworthy listing presentation
- Clear comparison of price, location, room type, and facilities
- Easy discovery near universities
- Convenient booking journey
- Responsive web experience

## Listing card — candidate content
- Property name and representative photo
- Area/location and proximity information if reliable
- Rent amount and billing period
- Room/property type
- Selected facilities
- Verification status and what it means
- View details action

## Property detail page — candidate sections
- Photos
- Description and location
- Rent, room type, capacity, and billing period
- Facilities such as Wi-Fi, mess, and laundry when confirmed
- Verification information
- Availability and booking instructions
- Cancellation/booking terms where applicable

## UX decisions to make
- How distance from a university is calculated and displayed
- Whether a map is included in the first version
- Which filters are essential at launch
- Whether users must sign in before booking
- How listing photos and verification badges are presented
- How unavailable, pending-review, or suspended properties appear

## Accessibility and responsive checks
- Keyboard navigation and visible focus
- Readable contrast and text sizes
- Clear form labels and error messages
- Mobile, tablet, and desktop layouts
- Avoid communicating verification status by color alone
