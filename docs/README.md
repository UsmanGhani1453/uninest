## How to use
- `Presentation-derived` means the presentation explicitly mentions the item.
- `Proposed for MVP` means a reasonable starting suggestion that still needs confirmation.
- `Open decision` means do not hard-code the behavior until it is agreed.
- Keep new ideas in a backlog; move them into the MVP only after considering time, complexity, and value.
